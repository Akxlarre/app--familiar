# Edge Function Discovery

Antes de crear una nueva Edge Function en `supabase/functions/`:

1. **Consultar** `supabase/functions/FUNCTIONS.md`
2. **Verificar** si ya existe una función que cubra el caso
3. **Leer** su `index.ts` si existe para entender su API
4. **Solo crear** cuando no exista alternativa

- Índice: `supabase/functions/FUNCTIONS.md`
